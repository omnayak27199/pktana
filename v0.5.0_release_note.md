# pktana v0.5.0 Release Notes

**Release date:** 2026-06-04
**Tag:** `v0.5.0`
**Tagline:** Multi-window browser UI · packages for every major distro · polished theming.

---

## Overview

pktana v0.5.0 turns the single-page Web UI from v0.4.0 into a true **multi-window packet workbench**. You can now open many interfaces in parallel — each in its own Chrome-tab-style window with independent packet stores, flow tables, protocol breakdowns, and hardware tabs — and pause/resume each one without disturbing the others.

In parallel, v0.5.0 lands a full **release-engineering pipeline**: native `.deb` packages for Ubuntu 22.04, Ubuntu 24.04 and Debian 12 alongside the existing RPMs for RHEL/Rocky/Alma 7 and 9, all built and uploaded automatically by GitHub Actions whenever a release is published.

---

## Major Features

### 🪟 Multi-window Web UI

- Each interface you open becomes its own window in the top tab strip.
- Inside every window: 📊 **Packets**, 🔗 **Flows**, 📈 **Protocols**, ⚙️ **Hardware** tabs.
- Backend tracks one independent SSE capture session per window via DashMap.
- The left activity bar now only carries **host-scoped** views: Server Info, PCAP Analyzer, Connections, Terminal.
- Hardware icon per interface is rendered via an attribute selector so it survives re-renders and theme switches.

### ⏯ Per-window Pause / Resume / Stop / Close

- **▶ Start Capture** is now explicit per window — opening a window no longer auto-starts capture.
- **⏸ Pause** halts the active session for that interface only; siblings keep running.
- **▶ Resume** appears only in the paused window.
- **⏹ Stop Capture** ends the session, **×** closes the window and cleans up backend state.

### 🏷 Handshake tag filters

One-click toolbar filters for the most common diagnostic flows:

- TCP SYN
- TLS Handshake
- DNS Query
- DHCP DORA

### 🌓 Polished light & dark theme

- Every button, form input, table header, and active state meets ≥ 3:1 contrast on both themes.
- `.btn`, `.form-input`, `.detail-header` and table styling redone for dark theme legibility.
- New rounded **"pktana"** wordmark in Nunito 800 with orange gradient, replacing the prior bitmap logo.

### 📦 Native packages for every major distro

Built and signed by CI on every release:

| Distro | Artifact |
|---|---|
| RHEL / Rocky / Alma 9, CentOS Stream 9 | `pktana-0.5.0-1.el9.x86_64.rpm` |
| RHEL / CentOS 7 | `pktana-0.5.0-1.el7.x86_64.rpm` |
| Ubuntu 22.04 | `pktana_0.5.0_amd64_ubuntu22.04.deb` + `.tar.gz` |
| Ubuntu 24.04 | `pktana_0.5.0_amd64_ubuntu24.04.deb` + `.tar.gz` |
| Debian 12 | `pktana_0.5.0_amd64_debian12.deb` + `.tar.gz` |

`.deb` packaging is driven by the new `[package.metadata.deb]` block in `crates/pktana-cli/Cargo.toml` and `cargo-deb`. RPMs use `deploy/centos/pktana.spec` with `pkg_version` injected from `release.conf`.

### 🤖 Automated release workflow

`.github/workflows/release.yml` triggers on `release: created` / `published` (or `workflow_dispatch` with a tag). It runs three jobs:

- `rpm` matrix → `rockylinux:9` (el9) and `centos:7` (el7)
- `deb` matrix → `ubuntu:22.04`, `ubuntu:24.04`, `debian:12`
- `publish` → downloads every artifact and attaches them to the GitHub Release via `softprops/action-gh-release@v2`

No more local Docker juggling for releases — push a tag, create the release, walk away.

### 🌐 Refreshed landing page

`index.html` now ships a six-card **download grid** (one per artifact), the rounded wordmark, and strict `/`-only HTTP routing so unknown paths/queries return 404 instead of leaking the index.

## Installation

### RHEL / Rocky / Alma / CentOS 9

```bash
sudo dnf install -y \
  https://github.com/omnayak27199/pktana/releases/latest/download/pktana-0.5.0-1.el9.x86_64.rpm
```

### RHEL / CentOS 7

```bash
sudo yum install -y \
  https://github.com/omnayak27199/pktana/releases/latest/download/pktana-0.5.0-1.el7.x86_64.rpm
```

### Ubuntu 22.04 / 24.04 · Debian 12

```bash
curl -L -o pktana.deb \
  https://github.com/omnayak27199/pktana/releases/latest/download/pktana_0.5.0_amd64_ubuntu24.04.deb
sudo apt install -y ./pktana.deb
```

Substitute `ubuntu22.04` or `debian12` as needed.

### Build from source

```bash
git clone https://github.com/omnayak27199/pktana
cd pktana
cargo build --release --features pcap,tui
./target/release/pktana --version
```

## Upgrade notes

- **Web UI URL is unchanged**: `http://<host>:<port>/` still serves the dashboard.
- The activity bar layout changed — per-interface views moved into per-interface windows. Any browser bookmark to a specific tab inside the old single-window UI will land on the host view; reopen the interface to get a new window.
- `pktana web` still defaults to background daemon mode. Use `-f` for foreground.
- All v0.4.0 REST/SSE endpoints remain stable; v0.5.0 adds the per-session lifecycle endpoints (`POST /api/sessions/create`, `GET /api/sessions`, `POST /api/sessions/{id}/stop`, `DELETE /api/sessions/{id}`).

---

## Breaking changes

None at the public CLI or `pktana-core` library level. The Web UI's internal DOM/event surface was reorganised around per-window state — any external tooling that scraped the previous single-window HTML will need updating.

---

## Known issues

- Browser tab strip can horizontally overflow once a large number of interfaces is opened simultaneously; future release will add scroll arrows.
- Terminal panel still depends on local `xterm.js` assets; when serving over the public internet, place behind a reverse proxy with auth.
