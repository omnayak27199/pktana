# pktana v0.4.0 Release Notes

**Release Date**: May 10, 2026

## 🎉 Highlights

pktana v0.4.0 introduces a **Web UI server** for browser-based packet analysis alongside the existing TUI, while maintaining all v0.3.0 DPI capabilities. Now you can choose your interface: terminal or browser!

---

## 🚀 New Features

### Web UI Server
- **HTTP Server**: Built-in lightweight web server accessible at `http://0.0.0.0:8080` (default)
- **Live Interface Dashboard**: Real-time capture interface selection and live packet stream with auto-refresh
- **Interactive Packet Table**: Browse captured packets with sortable columns (Time, Bytes, Proto, Source, Dest, Info)
- **Deep-Dive Packet Inspector**: Click any packet to view full L2–L7 DPI details, including:
  - Protocol headers (Ethernet, IP, TCP/UDP, etc.)
  - Application protocol info (TLS SNI/ALPN, HTTP method/path, DNS entropy, SSH banner, etc.)
  - Risk scoring and classification
  - All 0.3.0 DPI fields (JA3, QUIC version, NTP mode, BGP ASN, tunnel inner frames, etc.)
- **Connection Explorer**: Live connection list with GeoIP country, service name, TCP state, process info
- **Statistics Dashboard**: Packet/byte breakdown by protocol, top talkers with GeoIP
- **System Info Panel**: Kernel version, hostname, uptime, memory usage
- **CLI Integration**: Start web server with `pktana web [interface] [--port 8080]`

### Enhanced TUI
- **Responsive Rendering**: Improved terminal layout and redraw performance
- **Better Color Coding**: Protocol-specific color highlighting for enhanced visibility
- **Extended DPI Display**: Full integration of all new DPI fields from 0.3.0 (JA3, ALPN, QUIC, SSH banner, etc.)

---

## 📋 What's Changed

### Dual Interface Support
- Choose between TUI (`pktana tui <interface>`) or Web UI (`pktana web <interface>`) for packet analysis
- Both interfaces leverage the same underlying DPI engine for consistent analysis

### Improved Architecture
- Web UI and TUI now share the same underlying DPI engine and capture mechanisms
- Added `web.rs` module to pktana-cli for HTTP server implementation
- No breaking changes to the DPI engine or packet analysis logic from 0.3.0

---

## 🔧 Technical Details

### New Components
- `web.rs`: HTTP server implementation with rich HTML dashboard
- Web server backend handles live capture, packet inspection, and connection tracking
- Shared architecture with existing CLI components

### Compatibility
- ✅ All v0.3.0 DPI capabilities fully supported
- ✅ Backward compatible with existing capture and analysis workflows
- ✅ No breaking changes to the core library

## 📦 Installation

### RPM (RHEL 9 / Rocky / CentOS Stream 9)
```bash
sudo dnf install https://github.com/omnayak27199/pktana/releases/latest/download/pktana-0.4.0-1.el9.x86_64.rpm
```

### From Source
```bash
cargo install pktana-cli --features pcap,tui
```

### Cargo Library
```bash
cargo add pktana-core
cargo add pktana-cli
```

---

## 🎮 Quick Start

### TUI (Terminal Interface)
```bash
pktana tui eth0
```

### Web UI (Browser Interface)
```bash
pktana web eth0 --port 8080
# Then open http://localhost:8080
```

---

## 📝 Notes

- Web UI requires a modern browser (Chrome, Firefox, Safari, Edge)
- Default port is 8080; use `--port` flag to customize
- Root/sudo privileges required for packet capture
- All DPI features from v0.3.0 are immediately available in the Web UI
