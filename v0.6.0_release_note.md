# pktana v0.6.0 Release Notes

**Release date:** 2026-07-20
**Tag:** `v0.6.0`
**Tagline:** Production DLP & IDPS engines · wired into every capture path.

---

## Overview

pktana v0.6.0 adds **production-grade security inspection** on top of the existing DPI pipeline. Two new engines ship in-tree:

- **DLP** — Sophos-style content identifiers for credentials, PII/PCI, and secrets in cleartext protocols
- **IDPS** — Suricata-style signatures, heuristics, JA3 blocklists, and custom rule lines

Both engines plug into **live capture, pcap analysis, Web UI, TUI, CLI, and MCP**, with conditional policy, per-interface stats, and clear-on-disable behavior.

---

## Major Features

### DLP (Data Loss Prevention)

- Built-in identifiers: HTTP Basic / Bearer / cookies, PAN/PCI, SSN, IBAN, passport patterns, bulk email/phone, private keys, cloud API keys
- Protocol-aware scanners for HTTP, FTP, and SMTP
- Custom regex identifiers with category and severity
- Engine actions: **monitor**, **drop**, or **redirect**

### IDPS (Intrusion Detection / Prevention)

- Signature catalog with Suricata-style SIDs
- Heuristics: port scan, SSH brute-force, DNS tunneling, NTP amplification, Telnet, large ICMP, suspicious ports
- DPI risk bridge and high composite risk-score alerts
- JA3 fingerprint blocklists and custom Suricata rule lines
- Per-signature threshold windows before alert

### Policy & operations

- Conditional policy rules (engine, interface, addresses, ports)
- Per-interface / per-session alerts, flows, and stats
- Clear-on-disable resets engine state cleanly
- Configurable from Web UI, CLI, TUI, and MCP tools

```bash

  https://github.com/omnayak27199/pktana/releases/latest/download/pktana-0.6.0-1.el9.x86_64.rpm
```
